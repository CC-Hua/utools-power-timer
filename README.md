# 电源定时

**在 uTools 里定一个时间，到点自动关机、重启或睡眠。执行前有倒计时，随时能反悔。**

---

## 一、这个插件是做什么的

夜里下载还没结束、渲染还要跑一个小时、想让电脑在自己睡着之后自动休息——这些时候，人不想守着，也懒得去记 `shutdown -s -t 3600` 这类命令，更不想为此打开「任务计划程序」。

电源定时把这件事收进 uTools：选一个操作，选一个时间，点「安排任务」。之后界面上是实时倒计时，到点前会提醒你，到点执行。中途改主意，点一下就能取消。

**同一时间只保留一个任务**：安排新任务会替换旧的，不会出现两条关机指令互相打架的情况。

## 二、核心功能

**三种电源操作**
关机、重启、睡眠，一键切换。睡眠适合短时间离开，关机适合结束一天，重启适合更新之后。

**两种设定方式**

- **倒计时**：15 分钟、30 分钟、1 小时、2 小时、8 小时五个常用档，也可以自己填数值和单位（1 分钟至 7 天）。适合「再给我一小时」这种模糊但常见的需求。
- **指定时间**：用时间选择器精确定到某天某时某分；另有「今天 23:00」「明天 07:00」「明天 09:00」三个预设，一键填好。

**到点前的两重提醒**
默认提前 5 分钟弹一条系统通知（可选不提醒 / 1 / 5 / 10 / 30 分钟），最后 10 秒再补一条。点通知就能回到插件取消任务——这是最后一道人为拦截。

**随时取消与修改**
任务卡片上直接有「修改」和「取消任务」。修改会整体替换旧任务并移除它的后台定时，不会叠加；取消会同时清掉 uTools 后台定时和本机计时器，系统侧不留任何待执行的关机计划。

**防误关机**
到期后只给 2 分钟迟到窗口，超过就标记「已错过」并且**不执行**——不会因为你隔天才打开插件，电脑突然关机。已过期或已错过的任务，必须点「立即执行」并在 4 秒内再确认一次，才会真的执行。

**演练模式**
勾上之后，到点只弹通知、不真正执行，通知里会带上原本要运行的命令。第一次用，或者不确定时间算得对不对，先演练一遍。

**环境透明**
界面底部可以展开「运行环境 · 所需权限 · 实际执行的命令」，直接列出当前系统上三条操作各自会调用什么命令。不用翻代码，也不用猜它到底做了什么。

**强制关闭程序（仅 Windows）**
关机、重启时可勾选，等价于 `shutdown /f`，用于有程序卡住不肯退出的情况。睡眠不提供此项。

## 三、适用场景

| 场景 | 怎么设 |
| --- | --- |
| 睡前挂下载、渲染、编译 | 倒计时 1～2 小时，到点关机 |
| 下班或离开工位 | 指定时间，今天 18:30 关机 |
| 远程连回家里或公司的电脑 | 提前设好时间，免得忘关 |
| 系统更新完想夜里重启 | 指定凌晨时间重启 |
| 只想省电、不想彻底断电 | 定时睡眠 |
| 展厅、演示机闭馆前关机 | 指定打烊时间关机 |

## 四、典型使用方式

**例 1：下载跑完自动关机**

1. 搜索「定时关机」打开插件
2. 操作选「关机」，触发方式选「倒计时」，点「2 小时」
3. 提前提醒保持默认的 5 分钟，点「安排任务」
4. 卡片开始倒计时；想提前睡，点「取消任务」即可

**例 2：明早七点前重启**

1. 操作选「重启」，触发方式切到「指定时间」
2. 点预设「明天 07:00」，确认预览显示的时间无误
3. 点「安排任务」

**例 3：先确认时间算得对不对**

1. 按上面任一种方式设好时间和操作
2. 勾选「演练模式」，再点「安排任务」
3. 到点收到通知，说明时间点算对了；回到插件关掉演练、重新安排即可

**例 4：任务设错了**

任务卡片上点「修改」，表单会带回原来的设置，改完点「保存修改」，旧任务自动作废；或者直接点「取消任务」，任务不会执行。

## 五、适用系统与权限

| 系统 | 实际执行的命令 | 权限与限制 |
| --- | --- | --- |
| Windows 10 / 11 | 关机、重启：`shutdown.exe /s` `/r /t 0`；睡眠：`rundll32.exe powrprof.dll,SetSuspendState 0,1,0` | 普通用户即可。域策略、远程桌面会话或缺少「关闭系统」权限时会被系统拒绝；已启用休眠的机器可能进入休眠而非睡眠 |
| macOS 12 及以上 | `osascript -e 'tell application "System Events" to …'` | 首次执行会弹「自动化」授权，需在 系统设置 → 隐私与安全性 → 自动化 中允许 uTools 控制 System Events |
| Linux（systemd） | `systemctl poweroff` / `reboot` / `suspend` | 经 systemd-logind 与 Polkit 处理，需要本地活动会话；仅 SSH 会话或策略收紧时可能要求认证或失败 |

## 六、使用边界

- **uTools 需要开着**（可以最小化到托盘）。彻底退出 uTools，任务不会触发。
- 首次登记后台定时，uTools 会弹窗请你确认。若拒绝，任务仍然可用，但只在插件与 uTools 运行期间有效，卡片上会标出提示。
- 时间范围：至少在 5 秒之后，最多 7 天之内。
- 一次只保留一个任务。
- Windows 上若系统启用了休眠，睡眠指令可能让机器进入休眠。这是系统行为，插件无法改变。
